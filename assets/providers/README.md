# Provider marks

- `openai.svg`: OpenAI provider mark selected by the project owner.
- `gemini.svg`: Google Gemini provider mark selected by the project owner.
- `groq.svg`: Groq provider mark selected by the project owner.

The corresponding PNG files are 256x256 transparent rasterizations used by the
Windows application. All names and marks remain property of their respective
owners and identify the related API provider only.
