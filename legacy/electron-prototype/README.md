# Archived Electron prototype

This directory contains the incomplete Electron/TypeScript implementation that
preceded the current Python desktop application.

It is preserved for project history only. It is not installed, tested,
packaged, or used by ClarifyVoice today, and the root `package.json` does not
contain its former dependency graph.

Do not add current product behavior here. Active development belongs in
`app.py`, the focused Python modules at the repository root, and `tests/`.
